# Zap geometry acceptance

Three complete exact research functions (696 bytes,38 operands) are integrated with one shared OP_VEC3 definition and canonical symbols. `op_generate_zap_points` at0043d6b1 replaces its prior fixture stand-in; `op_subdivide_zap` at0043d784 implements the real recursive midpoint generator. `op_zap_draw_opaque` at0043d8ca joins the existing segment and default wrappers. No duplicate implementation is introduced at either address.

The unsized shared vector declaration establishes no original allocation capacity. The fixture defines19 owned vectors: the17-point prefix required by depth4 callers and two trailing guards. All tested writes/copies stay within0..16; the direct subdivision base1/depth4 case is omitted from shared integration. Only supported depths0..4, segment clamp inputs5/INT_MAX, disjoint destinations and exact snapshot aliasing are claimed.

Connected fixtures execute real build and subdivision. They verify counts2/3/5/9/17, literal RNG counts0/3/9/21/45, left-first midpoint/coordinate order, intermediate stores and callback mutations. The material is captured before generation for segment/default, while opaque generates and copies before resolving the live sprite. Submit callbacks observe and mutate actual owned state. The independent direct subdivision cases retain endpoint capture/mutation evidence.

Expected arrays and all guards are captured before calls. Expected writes are explicit. Ideal midpoint biases for authored Pythagorean endpoints are tabulated independently using rational arithmetic. Only predicted middle coordinates use a finite1e-5 behavioral tolerance for x87 rounding; endpoints, untouched components, input objects, trailing guards and passed bit patterns are checked exactly. This behavioral tolerance does not change byte matching: every compiled function still requires a complete zero-difference comparison with verified operands.

Input alias cases cover disjoint endpoints, identical endpoints, end pointing at scratch0 (overwritten by the first store) and start pointing at the final scratch slot (overwritten before delta calculation). Partial shifted snapshot overlap and invalid shifts/buffers are outside the evidence domain. Width bit patterns are forwarded without interpreting their floating-point value. Geometry arithmetic claims remain finite only.

The original game, graphics, random generator and resource callbacks are never executed. External callbacks are authored fixture boundaries. Frozen focused research remains unchanged; old wrapper-only fixture headers are retained as historical files but are no longer included or used as acceptance evidence. Acceptance requires clean full VC5 comparison and shared fixtures; see [acceptance017](../research/acceptance-017/result.json). Whole-executable identity remains pending.
