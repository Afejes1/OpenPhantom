# World names and restart acceptance

The animation-name reader, temporary actor-name helper and restart-clock routine share OP_B3D_WORLD and OP_B3D_HEADER. New fields preserve all previously accepted offsets and extents. A four-byte length/name-pointer union and typed actor pointers represent the observed32-bit layout. The mangle loop explicitly uses a signed interpretation of the shared unsigned count word.

The animation reader retains the original cursor while a stream callback may retarget the table whose entries receive pointers. It publishes count and size before an optional allocation and returns success even if allocation returns NULL. Fixtures use bounded owned tables, independently specified pointer offsets and signed size words without real I/O.

The restart source uses current_ticks/previous_ticks and the shared float delta field. A narrow original-toolchain probe proved its complete58-byte span before integration. Its real helper call resolves to the reconstructed temporary-name function. Shared fixtures run the actual read then restart; the timer observes the complete prior state, mutates fields and an unrelated byte, and the fixture checks final overwrites/retention. Actual actor pointers refer to authored owned records. The behavior fixture proves no external writeback from name normalization; exact158-byte code equality proves the temporary local processing exists.

The existing read/allocation backends dispatch to this fixture only while its explicit active flag is set. All previous test bodies are retained. No byte exclusions or warning waivers are added. Final linked retail placement and complete executable identity remain separate work. See research/acceptance-006/result.json for immutable acceptance when completed.
