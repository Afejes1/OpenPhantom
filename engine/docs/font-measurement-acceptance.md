# Font measurement and signed system slot

Two campaign037 functions share the actual reconstructed character/string measurement chain. The direct character fixture retains47280 checks, optional/aliased outputs, byte argument scope, negative/nonzero backend results and selected-record retargeting. The connected string fixture calls the actual character wrapper and routes only its scale and glyph-metric backends. It covers exact finite sums, high character bytes, callback selection changes and late measurement failures that write wrapper temporaries but leave the previous string width unchanged. Empty strings also return zero with no selection. A first failed nonempty measurement can leave an uninitialized width; no defined result is claimed or invented.
