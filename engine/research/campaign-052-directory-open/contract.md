# directory_open

Allocate524bytes and returnnull on allocation failure; otherwise zero all524bytes. Signed modes0/1/2 format pattern@8 with external all-format and path. Mode3 dereferences extension, skips exactly one leading dot, and formats with external extension-format,path,selected extension pointer. Other modes return the zeroed object without formatting. ExtensionNULL is tested only outside mode3. Formatter returns ignored. All allocation/path/extension/format state is authored and guarded; no input/object overlap.

No original program or real file enumeration/close/heap operation is executed. Strings, records and callbacks are authored. Full snapshots and explicit pre/post-callback expectations support the bounded behavior claims. No byte exclusions or warning waivers; individual functions remain distinct from shared acceptance and whole-executable identity.
