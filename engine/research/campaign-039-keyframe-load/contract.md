# keyframe_load

Use loader hook when nonnull. Otherwise allocate132 bytes, load entry on allocation success, return captured allocation on nonzero load result. Allocation/load failure calls keyframe_free even forNULL then returnsNULL. One allocator argument is established by disassembly; decompiler extra argument is not adopted.

Team not_done. Full function spans and all operands statically reviewed. Strict pinned VC5/Od/MT matches require zero full-span differences, no exclusions. Ten-attempt/fifteen-minute cap per function, stop after five non-improving attempts. Native compilation only; authored fixtures execute isolated Docker. Original executable never run.
