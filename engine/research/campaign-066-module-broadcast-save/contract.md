# module_broadcast_save

Dispatch authored module callbacks through the real accepted ID lookup, preserving return codes, argument words and live linked-list traversal.

Static target 0x0046F180, complete body and interval 125 bytes, no tail. Parent independently inspected all instructions; the independent reviewer checked callers and boundaries. Exact operand offsets are in target.json. All three callbacks use cdecl, three 32-bit words and caller cleanup12; pointer/float meanings are transported as opaque words. Restore has event11, opaque payload word,0 and zero default; save has event10,id,0 and zero default; general event has event,0,payload word and missing-ID default1. Broadcast id0 walks cached initial head forward for save or tail backward for general events, reading each current link after its callback. Broadcast callback results are discarded and final result is0. Restore id0 does nothing.

Focused fixture links finder.c copied from accepted module_find_by_id.c with only its include changed. Guarded owned lists cover lengths0..5, rotations, duplicate and signed IDs, missing IDs, zero/one/negative/extreme results, arbitrary event/payload words. Five distinct callbacks identify each visited node. Expected visit plans are calculated before calls from owned input and explicit mutation cases: truncate, skip second, or mutate only globals plus a future ID. Callback observations check full pre-state, exact order, argument words and signed returns. Global head/tail mutations verify cached starting nodes; current-link changes verify live traversal. Restore transports opaque words; an authored callback independently mutates guarded fixture storage, whose final bytes are checked. The observed save caller supplies a zero-extended16-bit word. No arbitrary pointer dereference, cycles, releases or original execution. Full node and payload bytes are checked after calls.
