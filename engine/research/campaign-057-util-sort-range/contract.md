# util_sort_range

Void cdecl sorts inclusive low/high using compare(index,index,context) and swap(index,index,context). Three genuine locals retain pivot and left/right partition boundaries. Bounded signed high-low<1 is a no-callback path; two-element comparison swaps only for positive return. General partition advances left on <=0, retreats right on <0, exchanges while separated, then adjusts partition limits and recurses on the smaller partition first. All four self-call operands are verified. Tests use independent insertion-sort final values, live snapshots updated only by authored swaps, full array/context guards, duplicates/extreme signed values, ascending/descending order, INT_MIN/0/INT_MAX callback results, empty/single ranges and bounded inclusive indices. A literal seven-event schedule for [3,1,2] also checks representative callback order. Guard failures abort the authored fixture before invalid indexing and a callback budget bounds accidental nontermination. No signed overflow or null active callbacks are claimed.

Independent static review confirmed all765 full bytes and9 address operands, with no alignment tails. Tokenize has one path-search caller, quote has no direct entry XREFs, and sort has its four recursive self-calls. All data/callbacks are authored; no original executable or decompiler output is included. No byte exclusions, warning waivers or whole-executable claim.
