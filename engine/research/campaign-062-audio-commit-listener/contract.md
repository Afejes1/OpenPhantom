# audio_commit_listener

Independently recovered cdecl wrapper over offset-asserted stdcall COM-shaped callbacks. Device slot0x18 receives window word and priority2. Buffer frequency uses0x44, Stop0x48 then current position0x34 withzero, Release0x08. Spatial max/min distance uses0x40 then0x44 (float max then min, deferred1); position/velocity0x4c/0x50 receive capturedxyz and1; mode0x48 receives unsigned mode and0; Release0x08. Listener commit uses0x44. The opaque32 availability gate is not assigned an unproved pointer/boolean meaning. The result local captures the actual HRESULT/ULONG, which void wrappers intentionally discard. CoInitialize passesNULL and returns HRESULT; CoUninitialize isvoid.

Owned object and vtable pairs verify all argument words, this identity, flags, call order and full guard/state snapshots. First-callback mutation swaps vtables, clears the gate, moves the listener global and changes vector inputs; Stop and distance bounds must use the new vtable for their second call despite the gate change. Vector arguments are all captured before callback mutation. NULL/gate skip paths are tested; enabled NULL frequency and enabled NULL spatial release are excluded because the original dereferences them. Ordinary finite float word patterns include signed zero; HRESULT patterns include success and high-bit failures. All callbacks are authored observers: no real COM, sound, OS or original executable runs. Repeated irrelevant dimensions make check count larger than unique scenario count. Exact full spans, no exclusions or warning waivers; shared acceptance remains separate.
