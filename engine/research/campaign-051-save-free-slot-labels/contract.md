# save_free_slot_labels

Visit exactly99 rows of stride8. For each live nonnull label atoffset4, release it, then clear that same field after the callback. Future slot mutations must affect later dispatch. Current-field replacement is overwritten with null; callbacks may insert earlier labels that are not revisited. Nonpointer words and surrounding guards remain unchanged. Null base is outside the domain; repeated handles are nonfreeing authored observers only.

All strings, buffers and callback services are authored. No original game, real file deletion/load, lifecycle dispatch or disk API execution occurs. Callback ordering, returned pointer identity, signed inputs, complete expected snapshots and bounded writes are checked as applicable. No byte exclusions or warning waivers. Shared acceptance and whole-executable identity remain separate.
