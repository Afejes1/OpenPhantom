# Campaign 074

Two retained near matches, neither accepted. Stream read has 11 differing bytes across its complete 244-byte span (4.5082%); stream bits has nine across its complete 209-byte span (4.3062%). The differences remain in local stack placement. The first best candidate for each is retained.

Each function used six implementation compiles and stopped after five consecutive nonimprovements. Source names, declaration ordering and initialization scopes did not resolve the stack layout. The coordinator final native/Docker pairs agree on function code and relocations; the fixtures pass 594,528 and 451,584 checks, respectively. These passing fixtures do not waive the differing bytes or establish acceptance. No further source experiments are authorized by this campaign cap.

The read fixture covers bounded positive item sizes, zero and nonnegative counts, direct read results, partial elements, refill sequences and callback mutation. The bit fixture covers counts 1..32, all one-bit masks plus zero, partial reads, exhaustion and high accumulator bits. Unsafe or undefined C domains remain excluded from execution as recorded in the contracts, not excluded from byte comparison. Refill is authored test support.

The 5% label is a scheduling threshold only. All full original bytes and mapped call operands remain part of the strict comparison. There are no byte exclusions, warning waivers or changes to the accepted registry from this campaign. A future revisit requires a new evidenced local-allocation hypothesis, not a renamed campaign or further blind name trials.
