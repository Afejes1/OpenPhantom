# util_tokenize

Cdecl returns the delimiter pointer itself, or NULL. Clears nonnull output first, calls span-delimiters, advances captured input pointer, calls find-delimiter, determines length from same-array pointer difference or intrinsic strlen, clamps to unsigned size-1, calls bounded copy for nonnull output, then writes final NUL. Fixture outcomes independently select prefix, token length and separator presence in owned terminated strings; observe exact callback pointers/order, mutate live token content and predict copy before candidate writes. Copy observer transiently writes a sentinel at final terminator to prove the wrapper store. Zero size wraps cap to UINT_MAX rather than underwrites; zero/UINT_MAX sizes are tested only with owned output large enough for the entire selected token. NULL output omits copy and stores while preserving returned delimiter identity. Delimiter/input/output guards and all untouched bytes are checked.

Independent static review confirmed all765 full bytes and9 address operands, with no alignment tails. Tokenize has one path-search caller, quote has no direct entry XREFs, and sort has its four recursive self-calls. All data/callbacks are authored; no original executable or decompiler output is included. No byte exclusions, warning waivers or whole-executable claim.
