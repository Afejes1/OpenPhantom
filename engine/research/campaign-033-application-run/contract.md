# application_run

Call initialization once. Zero result immediately shuts down and returns0. For any nonzero result, read live application mode after init; exactly1 runs campaign, all others the alternate hook. Then shut down once and return0. Init and branch callbacks may mutate mode; no saved mode or callback return can replace the literal zero return.

Native compile only; authored fixtures run isolated in Docker. Ten attempts/fifteen minutes, stop after five non-improving attempts.
